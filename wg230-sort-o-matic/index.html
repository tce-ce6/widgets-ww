    How to use this widget

    1. Pick a property at the top: Float or sink, See-through, or Hard or soft.
    2. Show the class the item that arrives on the belt.
    3. Ask the class for their answer.
    4. Tap the tray the class chooses.
    5. Watch the machine show the real result.
    6. Tap Next for the next item.
    7. Tap Reset to start the round again.
