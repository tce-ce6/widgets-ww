DNA Synthesis Widget – Implementation & Testing Guide

This document details the recent logic refinements for the WG121 widget to ensure accurate biological representation and robust UI behavior.

1. Final Logic Improvements

1.1 FIXED Dynamic DNA Helix (Vertical)

The solution modal's vertical DNA helix now accurately reflects the synthesized sequence.

  • Position Mapping: Pre-existing SVG base segments are now dynamically sorted by their Y and X coordinates using getBBox and querySelectorAll. This ensures that even though the SVG groups are exported in a non-sequential order, the logic correctly maps letters to their physical rungs.
  • Strand Representation:
    • The Left side represents the 5'→3' Complementary strand.
    • The Right side represents the 3'→5' Template strand.
  • Base-Pair Logic: Adenine (A) always pairs with Thymine (T) on turquoise and yellow segments, respectively. Guanine (G) pairs with Cytosine (C) on purple and pink segments.

1.2 UI Feedback Band Scaling

The feedback band for correct and incorrect answers has been enhanced for readability.

  • Font Size: Increased from 18px to 24px.
  • Padding: Increased from 14px 28px to 18px 36px to give the text more breathing room.

1.3 FIXED Full-Screen Backdrop

The semi-transparent backdrop (poc-svg-backdrop) used for modals now covers the entire browser window.

  • Overflow Handling: The SVG's overflow is dynamically toggled to visible when a modal is open, allowing the backdrop to "bleed out" from the SVG container and cover any letterboxed areas.
  • Dimensions: The backdrop size is now set to 1000% of the SVG viewBox to ensure full coverage on ultra-wide screens.

2. Technical Testing & Console Commands

2.1 Inspecting Sequence State

The internal state can be inspected in the browser console by accessing the global widget instance.

// Shows the generated 12-base template sequence console.log(WG121_WIDGET.state.templateSequence); // Shows which bases the user has placed so far console.log(WG121_WIDGET.state.placedBases);

2.2 Modal Layering Verification

Test that the backdrop covers all interactive elements by forcing a modal open.

// Forces the Insights modal to open WG121_WIDGET._openModal(WG121_WIDGET.state.cache.insightsModal);

3. How to Use (Instructions)

Follow these steps to complete the DNA synthesis activity:

  • Analyze the Template: Observe the top horizontal DNA strand. This is the 3' → 5' template.
  • Select Nucleotides: Click on one of the four nucleotides (Adenine, Thymine, Guanine, Cytosine) in the bottom tray.
  • Synthesize: The selected base will be placed into the next available slot on the complementary strand if it is the correct pairing (A↔T, G↔C).
  • Complete the Strand: Continue selecting bases until all 12 positions are correctly filled.
  • Explore Panels: Use the Show Answer button to view the double-helix representation and Insights for educational context.

4. Manual Testing Workflow

  1. Sequence Testing: Load the widget. Observe the top (Template) strand. Verify it is a random 12-base sequence.
  2. Synthesis Testing: Select a nucleotide from the bottom tray.
    • Selecting the Correct Partner (A↔T, G↔C) should advance the sequence and show a large green feedback band.
    • Selecting the Wrong Partner showing a large red feedback band with the correct base name.
  3. Solution Verification: Click "Show Answer". Compare the 12 horizontal base pairs with the vertical helix on the right. Verify that every rung in the helix matches the horizontal strands and uses the correct color-coded segments.
  4. Backdrop Verification: Open a modal and resize the browser window. Confirm the dark dimming layer fills the entire viewport without gaps.
