DNA Fingerprinting – Implementation & Testing Guide

This document details the logic implemented for the WG112 widget to ensure robust UI behavior and unbiased, non-repeating randomization.

1. Final Logic Implementation

1.1 NEW Multi-Selection Retry Logic

The widget now allows users to continue selecting suspects after an incorrect guess, rather than locking the UI.

  • Wrong Answer: Displays temporary red feedback for 1.5 seconds, then auto-dismisses and re-enables all suspect portraits.
  • Correct Answer: Locks selection, shows green feedback, and transitions the trial to completion.

1.2 NEW Unbiased Randomization (16 Combinations)

To ensure a fair distribution across suspects, the hardcoded criminal logic was replaced with a dynamic queue system.

  • Combinations: 4 distinct band pattern sets (chromosomes) × 4 suspects = 16 unique trials.
  • Non-Repeating Cycle: We maintain a shuffled criminalQueue of all 4 suspects. Each turn draws from this queue until empty.
  • Consecutive Prevention: If the first suspect of a new cycle matches the last suspect of the previous cycle, they are automatically swapped to ensure variety.

2. Technical Testing Approach

Testers can use two global helper functions in the browser console for verification.

2.1 State Verification

Run verifyRandomization() in the console to inspect the current hidden state of the active trial.

// Output shows current criminal index, lane mapping, and pattern data. verifyRandomization();

2.2 Distribution Testing

Run testDistribution(n) to simulate $n$ randomizations and verify that every suspect has a 25% probability.

// Simulates 100 trials and displays a results table. testDistribution(100);

3. Manual Testing Workflow

  1. Load the widget and complete electrophoresis.
  2. Intentionally select a Wrong Suspect. Verify the red box appears, then vanishes after 1.5 seconds.
  3. Select the Correct Suspect and verify the Bravo feedback appears.
  4. Click "New Set" and repeat 4 times. Verify that you have seen all 4 suspects exactly once as the criminal in that sequence.
