PPT NOTES – WIDGET SPECIFIC INSTRUCTIONS (MANDATORY)

Slide 2 – Objective

Objective: To determine sample DNA fragment sizes by comparing their
band positions with a standard DNA ladder on agarose gel
electrophoresis.

Use Case and User Interaction: - Users observe DNA band positions of
four samples alongside a DNA ladder. - Users estimate and enter fragment
sizes in base pairs (bps). - Immediate validation provides feedback. -
Five different sample sets provide varied practice scenarios.

------------------------------------------------------------------------

Slide 3

1.  User can select any of the five tubes in any order.
2.  User can press “Insight” button to view topic information.

Slide 4

1.  Pressing “Insights” opens a popup.
2.  Popup closes via cross button.

Slide 5

-   Selected tube must be highlighted.

Slide 6

-   After selecting the tube, a micropipette appears automatically.

Slide 7

-   The mixture is sucked into the micropipette (animation required).

Slide 8

-   Micropipette moves to Lane 1 for DNA ladder.
-   DNA ladder must always load into Lane 1.

Slide 9

-   Sample loads into Lane 1 via animation.

Slide 10

1.  Loaded sample marked with distinct color.
2.  User can select the second sample.

Slides 11–12

-   Repeat micropipette and suction animation.

Slide 13

1.  For non-ladder samples, micropipette must move to the next available
    lane.
2.  Even if tubes are selected in any order, loading must strictly occur
    from Lane 2 to Lane 5.

Slide 14

-   Sample loads into Lane 2 via animation.

Slide 15

-   Second sample marked with a different color.

Slide 16

1.  All lanes must be loaded sequentially.
2.  All sample tubes marked with different colors.

Slide 17

1.  After all lanes are loaded, Start and Reset buttons appear.
2.  Reset reloads samples from Slide 5 to Slide 16.

Slide 18

1.  Pressing Start triggers electrophoresis animation.
2.  DNA bands form.

Slide 19

-   Text boxes appear below sample tubes for manual entry.

Slide 20

-   Correct input: Green box + feedback message.
-   Incorrect input: Red box + feedback message.

Slide 21

1.  After all correct values:
    -   Success feedback appears.
    -   Reset button appears.
2.  Reset restarts from Slide 3.
3.  A new randomized sample set loads.
4.  Total 5 different sample sets.

Slide 22 – Sample Sets

Set 1: 500, 1000, 1400, 1700

Set 2: 300, 700, 1200, 2000

Set 3: 600, 800, 1900, 2100

Set 4: 100, 900, 1300, 1800

Set 5: 200, 600, 1100, 1500

The sets must appear randomly in the widget.
